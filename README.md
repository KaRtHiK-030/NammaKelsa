# 📱 App Overview

NammaKelsa helps workers showcase their skills and enables hirers to find trusted professionals quickly and efficiently.

The platform includes:

- 👷 Worker Registration & Profiles
- 🧑‍💼 Hirer Authentication
- 🔍 Smart Worker Search
- 💬 Real-Time Chat System
- ❤️ Favorite Workers
- ⭐ Reviews & Ratings
- 📩 Request Management
- 🔥 Firebase Integration

---

# ✨ Key Features

## 👷 Worker Module

- Worker registration and login
- Profile creation and editing
- Skills and experience management
- Availability management
- Review and rating visibility

## 🧑‍💼 Hirer Module

- Hirer authentication
- Browse workers by skills
- Save favorite workers
- Send hiring requests
- View worker profiles and ratings

## 💬 Chat System

- Real-time messaging
- Worker-hirer communication
- Firebase-powered chat functionality

## ⭐ Review & Rating System

- Review workers after task completion
- Star rating system
- Improved trust and transparency

## 📩 Request Management

- Send work requests
- Accept or reject requests
- Track request status

# ⚙️ Installation Guide

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/KaRtHiK-030/NammaKelsa.git
```

---

## 2️⃣ Open in Android Studio

Open the project folder using Android Studio.

---

## 3️⃣ Sync Gradle

Allow Gradle to sync all dependencies automatically.

---

## 4️⃣ Configure Firebase

Add your Firebase configuration file:

```text
google-services.json
```

Place it inside:

```text
app/
```

---

## 5️⃣ Run the Application

Connect an emulator or Android device and run the app.
