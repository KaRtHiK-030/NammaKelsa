# NammaKelsa

NammaKelsa is an Android application that connects workers and hirers on a single platform.

## Features

- Worker and Hirer authentication
- Worker profile management
- Skill listing
- Search and browse workers
- Save favorite workers
- Chat functionality
- Request management system
- Reviews and ratings
- Firebase integration

## Tech Stack

- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Realtime Database / Firestore
- Jetpack Compose

## Project Structure

- Worker Module
- Hirer Module
- Chat System
- Request & Review System
- Profile Management
